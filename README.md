# Mini NPU: MAC 패턴 판별기

## 실행 방법

- Python 3.8 이상에서 실행합니다. 외부 패키지는 필요하지 않습니다.
- `python main.py`를 실행한 뒤 `1`은 사용자 입력 3×3 모드, `2`는 JSON 일괄 분석 모드를 선택합니다.
- JSON 모드에서 경로를 비우면 같은 폴더의 `data.json`을 읽습니다. 별도 JSON 경로도 입력할 수 있습니다.
- `data.json`에는 `filters.size_N.cross/x`와 `patterns.size_N_idx.input/expected` 구조가 필요합니다.
- 수동 모드는 필터 A, 필터 B, 입력 패턴 순으로 각 행의 숫자를 공백으로 구분해 입력합니다. 잘못된 행이나 숫자가 있으면 해당 행렬을 처음부터 다시 입력합니다.

## 구현 요약

- 행렬 검증 후 MAC은 표준 라이브러리만 사용한 중첩 반복문으로 계산합니다.
- 점수는 각 위치의 입력값과 필터값의 곱을 누적한 값입니다.
- 내부 표준 라벨은 `Cross`, `X` 두 가지입니다. expected의 `+`와 `cross`, 필터 키의 `cross`, 그리고 소문자 `x`를 표준 라벨로 바꿉니다.
- 두 점수 차이의 절댓값이 `1e-9` 미만이면 `UNDECIDED`로 판정합니다. PASS는 Cross/X 판정이 정규화된 expected와 같을 때만 부여합니다.
- JSON 키에서 N을 읽어 `size_N` 필터를 고릅니다. 키 형식, 배열의 정방형 여부와 크기, 라벨, 필수 필드 오류는 케이스 단위 FAIL로 기록합니다.
- 패턴 생성기 `generate_pattern(N, "Cross" 또는 "X")`는 N×N 이진 패턴을 만듭니다. Cross는 가운데 행과 열, X는 두 대각선을 채웁니다.

## 성능 분석

프로그램은 각 크기에서 같은 생성 패턴과 필터를 사용해 10회 MAC을 반복하고, 함수 호출 구간의 평균 시간을 밀리초로 표시합니다. 2차원 인덱싱과 평탄화한 1차원 인덱싱을 나란히 측정해 메모리 접근 최적화 전후를 비교합니다. 표의 연산 횟수는 단일 MAC의 곱셈 누적 횟수 N²입니다. 짧은 실행 시간은 시스템 부하와 Python 인터프리터 상태에 따라 달라질 수 있습니다.

## 결과 리포트

- 제공된 데이터는 `size_5_1`부터 `size_25_2`까지 총 6개 케이스이며, 정상 데이터라면 케이스마다 입력/필터 크기를 검사한 뒤 Cross와 X 점수를 비교합니다.
- `+` expected는 `Cross`로, `x` expected와 `x` 필터 키는 `X`로 정규화합니다. 원본 표기 차이만으로 생기는 잘못된 비교를 막습니다.
- 정상 케이스의 PASS/FAIL은 점수에서 계산된 판정과 정규화된 expected를 비교해 결정합니다.
- 동일 점수 또는 차이가 epsilon보다 작은 경우 임의로 한 라벨을 선택하지 않고 `UNDECIDED`를 반환합니다.
- 따라서 expected가 Cross/X인 케이스가 동점이면 PASS 처리되지 않고 FAIL로 보고됩니다. 이는 실제 구분이 불가능한 상황을 성공으로 위장하지 않게 합니다.
- 부동소수점은 십진 소수를 이진수로 근사하므로 수학적으로 같은 점수도 미세하게 다를 수 있습니다.
- `1e-9` 허용오차를 쓰면 이런 작은 표현 오차 때문에 우연히 한쪽 점수가 더 큰 것으로 판정되는 일을 줄일 수 있습니다.
- FAIL은 케이스 식별자와 요약 사유를 출력합니다. 원인은 지원하지 않는 라벨, JSON 키/필드 오류, 잘못된 2차원 구조, 크기 불일치, 예상 라벨과 실제 판정 불일치로 구분됩니다.
- 크기 불일치는 해당 케이스만 FAIL 처리하며 전체 프로그램을 종료시키지 않습니다.
- 한 번의 MAC은 N²개 위치를 각각 한 번 처리하므로 시간 복잡도는 O(N²)입니다.
- N이 2배가 되면 연산 위치는 약 4배가 됩니다. 예를 들어 5×5는 25회, 25×25는 625회로 25배 차이가 납니다.
- 평탄화 배열도 산술 연산 수는 N²로 동일하지만 2차원 행 접근 단계를 줄입니다. 측정표는 실제 Python 환경의 이점을 보여주며, 작은 행렬에서는 측정 잡음이 차이를 가릴 수 있습니다.
- 1차원 변환 자체의 비용은 측정 구간에 넣지 않고 MAC 함수 호출만 측정합니다. 따라서 이 비교는 반복 계산에 평탄화 배열이 이미 준비된 경우의 접근 비용을 보여줍니다.
- 반복 횟수는 각 크기당 10회이며, 이는 짧은 연산의 단일 측정보다 평균값을 안정적으로 관찰하기 위한 최소 측정입니다.

### 제공 데이터 실행 결과

실행 환경에서 `python main.py`의 JSON 모드를 선택하면 실제 시간과 총 PASS/FAIL 및 실패 케이스를 확인할 수 있습니다. 측정 시간은 하드웨어와 실행 부하에 따라 달라지므로 실행 시 계산한 값을 기준으로 합니다.
